# Myn — Brand Identity
## "Your Data, Your Power."

---

## Brand Overview

**Role:** Consumer-facing personal data wallet
**Target Audience:** Privacy-conscious individuals, early adopters aged 25–45 who value digital autonomy
**Platform:** Mobile-first (iOS/Android) with web dashboard
**Domain:** Myn.app

---

## Brand Positioning

### Three-Word Essence
**Own. See. Choose.**

### Tagline
"Your data, your power."

### Positioning Statement
Myn is the personal data wallet that gives individuals complete visibility and control over their digital footprint. It transforms privacy from a passive shield into an active choice—see what you share, decide who accesses it, and earn when your data creates value.

### Core Value Proposition
- **See** everything you share across platforms
- **Control** who gets access and for how long
- **Earn** when your data creates value for organizations

## Visual Identity

### Color System

**Primary Gradient: Lavender → Sky**
```
Lavender:      #C5B6F7  — Soft, calming purple
Powder Blue:   #B8D4F1  — Transitional mid-tone
Sky:           #A7E2F2  — Light, airy blue
```

**Neutrals:**
```
Off-white:     #FDFCFF  — Background with subtle purple hint
Light gray:    #F5F5F7  — Card backgrounds
Mid gray:      #8E8E93  — Secondary text
```

**Accent:**
```
Frosted glass: #FFFFFF at 8% opacity
Iridescent hover: Subtle rainbow shimmer on interaction
```

**Color Psychology:**
- Purple = sovereignty, dignity, wisdom
- Blue = trust, calm, clarity
- Gradient = transition from control to freedom

### Typography

**Primary Typeface:** Inter or Satoshi
- Rounded, geometric, friendly
- High legibility at small sizes
- Modern without being cold

**Weight Usage:**
- Light (300): Body text, descriptions
- Regular (400): Standard UI copy
- Medium (500): Emphasis, buttons
- Semibold (600): Headlines (rarely used)

**Style Guidelines:**
- Always use sentence case (never all-caps except for micro-labels)
- Line height: 1.6 for readability
- Letter spacing: Slightly loose for calm feel (-0.01em)

**Example Hierarchy:**
```
Headline (24px, Medium):     "Your data, visible"
Body (16px, Light):          "Connect your accounts to see everything you share."
Button (16px, Medium):       "Connect first source"
Label (12px, Regular):       "Last updated 2 min ago"
```

### Iconography

**Style:**
- Thin-line circular icons (2px stroke weight)
- Orbital ring motifs representing cycles and control
- Monochrome by default, gradient fills on active states
- Soft drop shadows, no hard edges

**Icon Categories:**
- **Data sources:** Social, location, financial, health (each with unique orbital design)
- **Actions:** Share, pause, revoke, earn (circular motion emphasis)
- **States:** Active (glowing gradient), paused (muted), revoked (faded)

**Example Icons:**
```
Share:    Circle with arrow extending outward
Revoke:   Circle with X dissolving
Earn:     Circle with currency symbol, subtle pulse
Control:  Orbit rings with center point (user)
```

### Logo Design

**Primary Logo:**
- Letter "M" formed as a closed loop (symbolizes continuity and self-ownership)
- Can morph subtly when user gives consent (visual metaphor for control)
- Available in gradient and monochrome versions

**Logo Variations:**
```
Full color:     Lavender → Sky gradient
Monochrome:     Single color for light/dark backgrounds
Icon only:      Circular "M" loop for app icon
Animated:       Gentle rotation or breathing effect
```

## UI/UX Direction

### Design Principles

1. **Visibility First** — Users should see everything, immediately
2. **Tactile Control** — Interactions should feel physical and satisfying
3. **Calm, Not Loud** — Design should reduce anxiety, not create it
4. **Progressive Disclosure** — Complexity revealed only when needed

### UI Components

**Card-Based Dashboard:**
- Frosted glass cards with subtle shadows
- Each data source gets its own card
- Hover state: gentle glow effect
- Tap state: subtle scale animation

**Toggles & Switches:**
- Large, tactile toggle switches for share/pause/revoke
- Clear visual states (green = active, gray = paused, red = revoked)
- Haptic feedback on mobile
- Confirmation animation (gentle bounce)

**Data Visualization:**
- Minimal charts showing data usage over time
- Soft gradient fills, no harsh grid lines
- Focus on clarity over density

**Rounded Corners:**
- Standard radius: 16px (cards, buttons)
- Small radius: 8px (input fields, tags)
- Large radius: 24px (modal windows)

### Motion Language

**Easing:**
```css
cubic-bezier(0.4, 0.0, 0.2, 1) — Gentle, natural
```

**Timing:**
- Micro-interactions: 200ms
- Page transitions: 400ms
- Loading states: Continuous breathing animation

**Animation Types:**
- **Hover glows:** 200ms fade-in on interactive elements
- **Page transitions:** Soft vertical slides
- **Consent toggle:** Breathing animation when pending approval
- **Success states:** Gentle confetti or particle effect

**Motion Philosophy:**
All animations should feel calm, continuous, and gravity-based. No jarring snaps or aggressive bounces.

## Competitor Landscape

**Direct Competitors:**
- Privacy-focused data wallets (emerging category)
- Personal data marketplaces (few established)

**Adjacent Competitors:**
- VPN services (NordVPN, ExpressVPN)
- Privacy browsers (Brave, DuckDuckGo)
- Password managers (1Password, Bitwarden)

**Myn's Advantage:**
- Only solution that shows *and* monetizes data
- Blockchain-verified consent (provable ownership)
- Beautiful, consumer-friendly design
- Part of larger ecosystem (Ethos + Continuum)

## Launch Strategy Highlights

**Phase 1: Early Adopters (Months 1-3)**
- Target privacy advocates, crypto-native users
- App Store optimization for "data privacy" keywords
- Content marketing: "Privacy isn't hiding. It's owning."

- YouTube explainer videos

**Phase 3: Network Effects (Months 7-12)**
- Referral program (invite friends, earn DOT)
- Integration with popular apps/platforms
- B2B2C partnerships (Ethos customers → Myn users)
