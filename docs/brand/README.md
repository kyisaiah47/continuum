## Visual Design Principles

### Shared DNA Across All Products

1. **Loop/Ring Motif** — Circular, orbital, or infinite loop symbolism
2. **Gradient Philosophy** — Each uses gradients but different tonal ranges
3. **Motion Language** — Slow, gravity-based, continuous (no jarring snaps)
4. **Typography Family** — Inter appears across entire ecosystem
5. **8px Base Grid** — Shared spacing system

### Differentiation

- **Myn:** Soft, rounded, frosted glass, lavender/sky
- **Ethos:** Sharp, geometric, glass morphism, navy/cyan
- **Continuum:** Architectural, network-based, iridescent threads, near-black

## Dos and Don'ts

### ✅ DO

- Use sentence case (not all-caps except Continuum micro-labels)
- Maintain calm, professional tone
- Show cryptographic proof and verification
- Emphasize consent, ownership, trust
- Use gradient motifs consistently
- Keep motion slow and continuous

### ❌ DON'T

- Use crypto hype language ("LFG", "moon", "degen")
- Use aggressive disruption rhetoric
- Use emojis excessively (sparingly for social only)
- Ignore the shared design DNA (loops, gradients, Inter font)
- Rush animations (no jarring snaps)
- Overpromise or hype speculation
