## Brand Positioning

### Three-Word Essence
**Trust. Verify. Connect.**

"The ethical CRM."

### Positioning Statement
Ethos is the enterprise platform that transforms customer relationships from extraction to exchange. It enables organizations to access verified user data through transparent consent flows—turning compliance from a burden into a competitive advantage and data quality from a gamble into a guarantee.

## Visual Identity

### Color System

**Primary Colors:**
```
Deep Navy:         #101623  — Primary backgrounds
Elevated Navy:     #1A2332  — Card surfaces, elevated panels
Dark Slate:        #242D3E  — Hover states
```

**Accent Gradient: Silver → Cyan**
```
Silver Fog:        #B6C8E0  — Muted highlights
Steel Blue:        #7A9BBE  — Mid-tone accents
Electric Cyan:     #00C7FF  — Active states, CTAs
```

**Neutrals:**
```
Pure White:        #FFFFFF  — Primary text
Muted White:       #C8D1DB  — Secondary text
Border Gray:       #3A4A5E  — Dividers, borders
```

**Semantic Colors:**
```
Approved Green:    #00D88A  — Consent granted
Pending Amber:     #FFB84D  — Awaiting approval
Rejected Red:      #FF6B6B  — Access denied
Expired Gray:      #6B7280  — Time-limited access ended
```

**Color Psychology:**
- Navy = authority, trust, professionalism
- Silver/Cyan = technology, clarity, precision
- Dark background = focus, data-density, modern software

### Typography

**Primary Typeface:** GT America or Neue Haas Grotesk
- Geometric, authoritative
- High contrast between weights
- Modern without being trendy

**Secondary Typeface:** Inter (body text)
- Excellent readability at all sizes
- Harmonizes with Myn's typography

**Monospace:** IBM Plex Mono
- For consent IDs, transaction hashes, timestamps
- Adds technical credibility

**Weight Usage:**
- Light (300): Supporting text
- Regular (400): Body copy
- Medium (500): UI labels
- Bold (700): Headlines, important metrics

**Style Guidelines:**
- Headlines: Tight leading, high contrast
- Body: Spacious (1.5 line height)
- Data: Monospace for technical IDs
- Numbers: Tabular figures for alignment

**Example Hierarchy:**
```
Dashboard Metric (32px, Bold):   "247"
Metric Label (14px, Regular):    "Active consents"
Section Header (20px, Medium):   "Recent Requests"
Body Text (16px, Regular):       "Access valid for 30 days"
Technical ID (14px, Mono):       "0x4f8a...92c1"
```

### Iconography

**Style:**
- Geometric precision (hexagons, balanced scales, checkmarks)
- Duotone: Navy base + Cyan highlights
- 3px stroke weight (slightly heavier than Myn)
- Micro-animations on state changes

**Icon Categories:**
- **Consent States:** Approved (check), pending (clock), rejected (X), expired (calendar)
- **Data Types:** Email, location, browsing, purchases (each with unique geometric design)
- **Actions:** Request, approve, revoke, export
- **Analytics:** Chart, graph, funnel, timeline

**Example Icons:**
```
Approved:   Hexagon with checkmark, green accent
Pending:    Hexagon with clock, amber accent
Request:    Two hexagons connecting with arrow
Revoked:    Hexagon with strike-through, red accent
Export:     Hexagon with outward arrow
```

### Logo Design

**Primary Logo:**
- Stylized "E" that incorporates a balanced scale or checkmark
- Symbolizes ethics + verified access
- Available in full-color and monochrome

**Logo Variations:**
```
Full color:     Navy "E" with cyan accent
Monochrome:     Single color for presentations
Icon only:      "E" mark for compact spaces
Horizontal:     "E" mark + "ETHOS" wordmark
```

## UI/UX Direction

### Design Principles

1. **Clarity Over Density** — Present complex data without overwhelming
2. **Trust Through Transparency** — Show the full consent trail
3. **Action-Oriented** — Make next steps obvious
4. **Progressive Disclosure** — Advanced features available but not intrusive

### UI Components

**Modular Dashboard:**
- Glass morphism panels with blue tint
- Subtle backdrop blur (8px)
- Cards organized in responsive grid
- Clear visual hierarchy

**Consent Request Cards:**
- User avatar/initial
- Data fields requested (chips/tags)
- Time limit selector
- Payment amount
- Approve/Reject CTAs
- Timestamp and status badge

**Real-Time Audit Log:**
- Live feed of consent actions
- Timestamp (monospace)
- User ID (truncated hash)
- Action type (approved/rejected/revoked)
- Smooth fade-in for new entries

**Analytics Charts:**
- Line charts with gradient overlays
- Slow breathing animation (data flowing)
- No harsh grid lines (subtle guides only)
- Tooltips with detailed breakdowns

**Data Visualization:**
```
Approval Rate:     Circular progress (cyan gradient)
Active Consents:   Vertical bar chart
Request Funnel:    Horizontal funnel diagram
Time Series:       Smooth line chart with area fill
```

### Motion Language

**Easing:**
```css
cubic-bezier(0.25, 0.1, 0.25, 1) — Professional, confident
```

**Timing:**
- Micro-interactions: 250ms
- Panel transitions: 350ms
- Data updates: Stagger by 50ms per item
- Chart animations: 600ms ease-in-out

**Animation Types:**
- **Panel slides:** Horizontal reveals (left to right)
- **Data visualizations:** Lines drawing in smoothly
- **Consent cards:** Fade + slight upward slide on approval
- **Live updates:** Pulse effect on new entries
- **Glass surfaces:** Subtle particle effects (dust in light)

**Motion Philosophy:**
Professional and deliberate. Animations convey confidence and precision, not playfulness.

## Differentiation

### What Makes Ethos Different

**vs. Traditional CRMs (Salesforce, HubSpot):**
Ethos is built on verified consent, not scraped data. Every customer interaction is transparent and auditable.

**vs. Data Brokers:**
No opaque data purchases. Direct relationship between brand and customer. Fair compensation for data.

**vs. Survey Platforms:**
Real-time, ongoing data access (not one-time surveys). Blockchain-verified authenticity.
